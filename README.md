## 🚀 Local Setup & Running

1. **Clone the repository**:
   ```bash
   git clone https://github.com/mahi-8758/mahi-portfolio.git
   cd mahi-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
